# Assignment 01 — Personalized Greeting

**Page:** 01 — Hello World, package, imports, functions, variables, and strings  
**Difficulty:** Easy

## Question

Write a Go program that prints this exact output:

```text
Welcome to Go programming, Vansh!
```

## Requirements

1. Use `package main`.
2. Import the `fmt` package.
3. Create a `main()` function.
4. Inside `main()`, call a function named `welcomeUser` and pass the name `"Vansh"`.
5. Create `welcomeUser(name string) string`.
6. Make the function return the greeting message.
7. Print the returned message using `fmt.Println()`.

## Rules

- Write the code yourself; don't copy the example from the notes.
- Use only concepts covered on Page 1.
- Run `go build` to check that your program compiles.
- Don't look at a solution yet. Ask for a hint if you get stuck.
